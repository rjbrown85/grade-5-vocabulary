# Grade 5 Vocabulary

Reading, Writing, and Math vocabulary organized by Unit 1, Unit 2, and All words.

## Preview

Run `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Edit

Edit `vocabulary.json` and run `python3 build.py`. Styles and interactions are in `dist/style.css` and `dist/app.js`. The `dist` folder is the complete static website.

The vocabulary artwork is supplied classroom material. No license is granted for redistribution of that artwork.
